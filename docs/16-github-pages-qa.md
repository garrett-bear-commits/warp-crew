## One-time setup
1. Repo **Settings → Pages → Build and deployment → Source: GitHub Actions**
2. Push to `main` (workflow `Deploy GitHub Pages (QA)` runs automatically)
3. Wait ~1–2 min; open QA hub

Or: **Actions → Deploy GitHub Pages (QA) → Run workflow**
