## What this repo is

Warp Crew, a mobile-first idle space-crew game for the Jest platform (Boglight Games), in `apps/warpcrew/`
(plain JS + Vite), built on the owner's `game-core` foundation (everything else: pnpm workspace, TypeScript,
Fastify + Postgres server in `apps/server`, shared packages in `packages/`). The game-core port is described in
[`apps/warpcrew/docs/game-core-port.md`](apps/warpcrew/docs/game-core-port.md); stages 1–3 are done, stage 4
(staging + cut-over) is next.

## Commands (run from the repo root unless noted)

- Install: `corepack pnpm install` (Node 24, pnpm 10.30.1 via corepack).
- Game tests: `corepack pnpm -F @warpcrew/client test` (also `test:loop`, `test:ship`, `test:first-play`,
  `test:balance`). Game dev server: `corepack pnpm -F @warpcrew/client dev`. QA build: `build:pages`.
- Core checks: `corepack pnpm check`. Postgres tests: `corepack pnpm db:up` then
  `DATABASE_URL_TEST=postgres://postgres:postgres@localhost:55442/foundation_test corepack pnpm test:pg`.
- Warp Crew's local Postgres is the `warpcrew-postgres` container on **55442**. Never use `foundation-postgres`
  on 55432: other game-core projects on this machine share it.

## Rules the owner set (Garrett, Boglight Games)

- Never enter, paste or ask for secrets in chat (e.g. `JEST_PLAYER_SECRET`); the owner puts them into Railway.
- Ask before: creating or changing Jest Developer Console products, activating Jest production, turning on
  real-money minting (`purchases.mintPremium`), downloading files, and spending money (art generation budgets).
- Never ship real-money sales or production minting before staging checks pass and the owner approves.
- There are no real players yet (the owner is the only playtester): no data migrations are needed at cut-over.
- Publishing the GitHub Pages QA build is approved (see HANDOFF.md for the steps).
- Write player-facing copy and reports in plain language; the owner prefers short, concrete summaries.
