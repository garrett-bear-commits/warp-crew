# Core Loop — Detailed

## Session (3–8 min ideal)
1. Claim offline fuel + expedition results  
2. Read bridge status (fuel, crew, story)  
3. Travel (1 fuel typical): trade / combat / story / salvage  
4. Optional: launch or check expedition (crew lock, 15m test / 6h launch)  
5. Crew bay (level with medals) / gacha / ship slots  
6. Leave; Jest notifies on fuel full / expedition done  

## Fuel
- 1 fuel / hour, starting max 10, start with 8  
- Spent on travel (and later combat-heavy nodes)  
- No separate premium fuel currency — buy fuel with gems/packs  

## Expeditions
- Show success %  
- Crew unavailable until return  
- Early extract = fail  
- Gem skip (NYI in code, designed)  
- ~1 free meaningful expedition cadence; more via premium  

## Daily hooks
- Free gacha pull  
- Fuel regen returns  
- Login streak (designed; light implementation next)  
- Story drip (Eclipse Swarm / Hope’s Rest)
