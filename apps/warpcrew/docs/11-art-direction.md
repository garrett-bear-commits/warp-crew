# Art & UI Direction (from mockup)

Reference: user ship-interior mockup (FTL-like top-down rooms, hull/shield meters, objective, bottom nav).

## Tone
Cool, clean **retro pixel sci-fi** — professional idle, not grimdark, not cartoon slapstick.
- Space black + deep navy panels
- Cyan accent / blue shields / green hull
- Readable mobile-first UI
- Pixel art characters later (Sunnyside reskin)

## Screens
| Tab | Role |
|-----|------|
| SHIP | Bridge schematic, rooms, claim, travel shortcut |
| CREW | Roster, gacha, level with medals |
| MISSIONS | Expedition board (Derelict Freighter, Crystal Asteroid, Ice Outpost) + travel lanes |
| SHOP | IAP stubs |
| LOG | Captain's log |

## Ship fantasy
Top-down / cutaway starship with assigned crew in rooms (Bridge, Weapons, Engineering, Medbay, Cargo, Quarters). Full interactive FTL room combat is **not** v1 — schematic + assignment is enough for the Jest slice.
