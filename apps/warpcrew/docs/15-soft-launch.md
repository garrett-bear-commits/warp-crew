# Soft Launch Plan — Jest 7-day test

## Goal
Validate core loop retention + IAP intent for ~7 days of playable content, then expand.

## Player day loop (target ≤10 min)
1. Claim fuel / expedition  
2. 1–3 map jumps (trade / combat with assists)  
3. Launch or claim expedition  
4. Optional: gacha / hangar / shop  

## Funnel metrics to watch
- D1 / D3 / D7 return (Jest messaging should help)
- Free pull use rate
- Expedition launch rate
- Combat assist engagement
- IAP: starter pack CTR and convert
- Corvette gem interest (even if low N)

## Kill / keep criteria (rough)
- Keep iterating if D1 ≥ 25% of registered and sessions ≥ 2/day among returners
- Revisit fuel economy if players burn out of fuel in <3 min or never spend
- Revisit gacha if pull rate near zero after day 2

## Post-test backlog
- 6h expedition timers  
- Full Corvette cosmetics  
- More Swarm boss node  
- Cloud save via JestSDK.data  
- Art reskins (Sunnyside → mercs via Codex)
