# Sound effects credits

The sound effects in this folder are cut, leveled and re-encoded from these packs by
**Kenney** (https://kenney.nl), released under **Creative Commons Zero (CC0 1.0)**:

- Sci-fi Sounds — https://kenney.nl/assets/sci-fi-sounds
- Impact Sounds — https://kenney.nl/assets/impact-sounds
- Interface Sounds — https://kenney.nl/assets/interface-sounds

CC0 license: https://creativecommons.org/publicdomain/zero/1.0/

Credit is not required by the license; it is given here with thanks. Which source clip each
file comes from, and how it was cut, is listed in `src/data/sfxManifest.js`; the files are
built by `scripts/build-audio.mjs`.
